# Setting up links for TF setup

The setup expects the DAQ (4 channel xcvr) and the three 12-channel
devices, as in the TF setup for the apollo. 

Each of the `setup_links_L1T_DTCN.tcl` (N=1-4) presuemes that a fiber has been setup for the DTC receiver link N to connect to the L1T transmitter link.
